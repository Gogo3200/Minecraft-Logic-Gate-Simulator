# Minecraft-Logic-Gate-Simulator
Fully working logic gate simulator inside of minecraft using a datapack!

## Supported Versions
* 26.2

## How to Install
1. Create a new world, preferably a superflat with stone as the top layer.
2. place the zip into the datapacks folder
3. leave and rejoin.

## In-Game Menu
Press G to open the in-game menu.

## How to Use
* The datapack will automatically give you all of the essential blocks, including wires and gates.
* Levers and buttons are inputs; place them next to a wire and turn it on.
* Wool blocks are logic gates. They should be named accordingly. To get an output from them, you must place an output carpet next to it, along with a wire to see the output.

## Recommended extenstions
* Axiom is highly recommended for use in building bigger circuits
